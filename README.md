# Donut
* 自作Webアプリケーション専用モジュール管理リポジトリ

## 定義リソース
### Global
* グローバルリソースを定義
#### 実装したリソース
* ECRリポジトリ ← こいつもTerraform管理外でいいと思っている
* OIDCプロバイダー ← こいつも管理外でいいと思っている
* S3バケット
    * アプリケーションバイナリ配置用
    * LBのログ用
* Secrets Managerの箱だけ
    * 実際の値はDBインスタンスが依存するため, `data`で配置

#### 実装していないリソース
* Route53のホストゾーン
    * こいつに関しては, NS切り替えの際に最大48時間かかるので、あらかじめ作成しておく
* ACMのSSL証明書
    * 証明書の作成についても, 少し手順が面倒なのであらかじめ作成しておく
    * Terraformで自動化した方が都合がいい場合は作成

### IAM
* IAM関連のリソースを定義

### Network
* ネットワークリソース(恒久的)を定義
#### 実装したリソース
* VPC
* サブネット
* ルートテーブル
* インターネットゲートウェイ
* セキュリティグループ


### Data
* RDSやSecretsManagerの値を管理

### Runtime-network
* ランタイム中に必要なネットワークリソースを定義
* お金がかかるので基本は開発ごとにdestroyしたい


### Compute
* 実際のサーバを配置

#### 実装したリソース
* EC2インスタンス
* ターゲットグループとEC2インスタンスの紐づけ


### ECS
* ECSで動作させるリソースを定義
